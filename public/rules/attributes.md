# Характеристики

В Savage Worlds пять характеристик. Каждая начинается со значения **d4**.

| Название | Английское | Описание |
|---|---|---|
| **Ловкость** | Agility | Проворство, скорость реакции, координация |
| **Смекалка** | Smarts | Знание, находчивость, способность схватывать на лету |
| **Характер** | Spirit | Мудрость и сила воли; используется для выхода из шока |
| **Сила** | Strength | Физическая мощь; влияет на урон в ближнем бою |
| **Выносливость** | Vigor | Стойкость организма, сопротивление болезням |

## Стоимость повышения

У вас есть **5 очков** для повышения характеристик при создании персонажа. Каждое повышение на одну ступень стоит **1 очко**.

Максимум — **d12** (без расовых бонусов).
