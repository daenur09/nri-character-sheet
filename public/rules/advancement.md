# Прокачка персонажа

## Опыт (XP)

Ведущий выдаёт **1–3 пункта опыта** за игровую встречу. Каждые **5 XP** дают **одно повышение**.

## Ранги

| XP | Ранг |
|---|---|
| 0–19 | Новичок |
| 20–39 | Закалённый |
| 40–59 | Ветеран |
| 60–79 | Герой |
| 80+ | Легенда |

## Пять вариантов повышения

1. **Повысить характеристику** на одну ступень (не чаще 1 раза за ранг).
2. **Повысить один навык** на ступень, если он ≥ своему атрибуту.
3. **Повысить два навыка** на ступень, если оба < своих атрибутов.
4. **Изучить новый навык** со значением d4.
5. **Получить черту** (Edge) из доступных.
